## 🛠️ Tecnologias Utilizadas

- **HTML5 Semântico & Acessibilidade (SEO)**
- **CSS3 Moderno:** Design System com Glassmorphism, Neon Dark Mode, Grid/Flexbox e Micro-animações fluidas
- **Vanilla JavaScript (ES6+):** Arquitetura limpa sem dependências pesadas
- **Simulador Interativo de ROI:** Cálculo dinâmico em tempo real de retorno financeiro e horas economizadas
- **Terminal Interativo RPA:** Simulação em tempo real da execução dos robôs (`rpa_Expedicao`, SAP GUI Scripting, Playwright)
- **Modal de Detalhamento Técnico:** Visualização de arquitetura, stack e trechos de código

---

## 📂 Estrutura do Projeto

```bash
meu-portfolio/
├── css/
│   ├── animations.css    # Animações de brilho, fade, pulso e keyframes
│   └── style.css         # Variáveis CSS, layout, glassmorphism e componentes
├── js/
│   ├── main.js           # Navegação, filtros de projetos, modais e métricas
│   ├── roi-calc.js       # Lógica matemática e interativa do simulador de ROI
│   └── terminal.js       # Emulador do terminal interativo RPA
├── .gitignore
├── index.html            # Estrutura principal da aplicação
└── README.md
```
